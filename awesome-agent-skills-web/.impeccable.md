## Design Context

### Users
LionSaid Skills serves broad end users who want to find usable AI skills quickly without digging through GitHub or scattered source sites. They often start from a task, role, or trusted publisher rather than a repository name. The product needs to work for both English and Simplified Chinese users, with strong mobile usability because many discovery sessions start on phones.

### Brand Personality
Practical, direct, and trustworthy. The interface should feel fast to scan, lightweight, and confident rather than flashy or over-explained. It should help users reach a useful skill with minimal friction.

### Aesthetic Direction
Warm light surfaces, restrained glass treatment, and a red-first accent system that matches the LionSaid brand. Mobile interactions should feel compact and deliberate: bottom navigation for primary movement, bottom sheets for advanced controls, and floating utilities that never compete with core actions.

### Design Principles
1. Put discovery first: search and core navigation must stay obvious and reachable.
2. Reduce overlap: floating layers should stack cleanly and avoid covering one another on small screens.
3. Keep copy user-facing: labels should read like actions users understand immediately.
4. Preserve bilingual consistency: Chinese and English entry points should behave the same way.
5. Prefer progressive disclosure: keep advanced filters available, but out of the way until needed.
